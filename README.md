En este repositorio encontraremos una variedad de distintos ejercicios de PHP en donde se practicaran distintos aspectos basicos del lenguaje. Se dividen en 4 bloques de ejercicios con distintas tematicas entre ellos.

## Relacion 1

La relación consiste en practicar las características más basicas en PHP tales como los operadores, los bucles, los condicionales y funciones basicas de la clase math.
## Relacion 2

La relación 2 es ya más avanzada, consiste en tanto mejorar algunos ejercicios de la relación anterior atraves de mejorarla con CSS usando el framework de BootStrap, como de practicar la creación de frmularios, la captura de datos y la validación de los mismo tanto en PHP como JavaScript.
Se usan lo aprendido ya en la relación anterior como nuevas caracteristicas que se han aprendido en esta.
## Relacion 3

La relación 3 se practica la creación de funciones para luego usarlas en los distintos ejercicios y empezar a usar las variables de servidor de PHP para autollamar a la parte de código de PHP cuando envias el formulario.
## Relacion 4

La relación 4 se comienza a usar las Cookies y las sesiones para mantener los datos entre cambios de pagina y recargas de la misma página. Aparte de esto se comienza a crear clases personalizadas basicas con herencia y con la implementación de interfaces en alguna de ellas.
Se comienzan a crear los objetos genericos con StdClass para practicar la conversión a Json o a String para más adelante almacenarlo en las Cookies o para pasarlo a otras páginas y poder usarlas en las mismas.
